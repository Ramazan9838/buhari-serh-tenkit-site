# buhari-serh-tenkit-site

Buhârî Şerh Literatüründe Tenkit araştırma sisteminin şifreli yayın kopyası.

Adres: https://ramazan9838.github.io/buhari-serh-tenkit-site/

Bu depo yalnız giriş sayfasını (`index.html`) ve şifreli dosyaları (`kasa.json`, `veri/`) taşır; içerik AES-256-GCM ile şifrelidir ve yalnız şifreyle tarayıcıda açılır. Kaynak kod ve çalışma verileri ayrı, özel bir depodadır. Dosyaları elle düzenlemeyin; yeni sürüm özel depodaki `tools/yayin/yayinla.py` ile üretilir.
